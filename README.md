# PearlQuest

PearlQuest is a responsive React and Tailwind CSS travel-discovery app focused on Cebu Province.

## Run locally

1. Install Node.js (LTS).
2. Extract the ZIP.
3. Open a terminal in the folder containing `package.json`.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL printed by Vite.

## Included features

- Sign-up and sign-in demonstration before the dashboard
- Home dashboard with destination wheel and visible eligible choices
- Explore with search, category, budget, time, and sorting filters
- Destination detail pages with five quests per destination, tips, warnings, map links, and emergency guidance
- Quest detail pages with photo proof, notes, ratings, and XP rewards
- My Adventures, My Passport, profile, and a working Wishlist page
- Uploaded PearlQuest logo in `public/pearlquest-logo.jpg`
- Responsive layout built with Tailwind CSS
- Destination photo lookup through Wikimedia Commons search; relevant matching images load when online, with a built-in category fallback if a matching image is unavailable

## Notes

This is a front-end student project. Login is a local demo and is not secure server authentication. User data and wishlist items are stored in the browser. Destination costs and distance figures are planning estimates; verify details with local tourism offices and route details with Google Maps before travelling. Emergency call controls are intended as quick access to the Philippine emergency number 911 and are not a guaranteed dispatch integration.
